# Demo design

Inherit the current tarkan.dev community workshop identity. The single users page is an Operate surface: add a person, refresh, and observe persistence/cache reuse. Its task remains deliberately small.

Pine introduction/form alongside a pale green people list, 43%/57% desktop columns and a natural mobile stack. Barlow Condensed headings, Public Sans body, local licensed font files. Ochre identifies the Add person action. Rectangular controls, open ruled rows, initials instead of externally hosted portraits. Explicit loading, error, and empty states; semantic form labels and keyboard focus. Both system color schemes use the site's tokens. No Twoday logos, copy, assets, or dependencies are included.
